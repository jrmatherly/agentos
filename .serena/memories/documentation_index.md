# Documentation Index

## Generated Documentation

All documentation is in the `docs/` directory:

### Guides
- `docs/guides/GETTING_STARTED.md` - Quick setup and first chat
- `docs/guides/CREATING_AGENTS.md` - Build custom agents
- `docs/guides/DEVELOPER_GUIDE.md` - Local dev, testing, contributing

### API Reference
- `docs/api/openapi.yaml` - OpenAPI 3.1 specification
- `docs/api/index.html` - Swagger UI (interactive)

### Architecture
- `docs/architecture/ARCHITECTURE.md` - System diagrams (Mermaid)

### Code Reference
- `docs/CODE_REFERENCE.md` - All modules, functions, types

### Index
- `docs/README.md` - Documentation home page

## Quick Access

```sh
# View API docs (when running)
open http://localhost:8000/docs

# View local Swagger UI
open docs/api/index.html
```

## Updating Documentation

1. Edit files in `docs/`
2. Mermaid diagrams render in GitHub/VS Code
3. OpenAPI spec viewable via Swagger UI
